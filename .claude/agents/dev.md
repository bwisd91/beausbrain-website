Start the Next.js dev server for this project.

1. Check if dependencies are installed: `ls node_modules 2>/dev/null || npm install`
2. Run the dev server: `npm run dev`
3. The site is available at http://localhost:3000
4. Report any errors from the build output.

The project is a Next.js 15 app in the `/app` directory alongside a static `index.html`. The Next.js app is the primary codebase.
